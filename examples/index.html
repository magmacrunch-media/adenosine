adenosine examples

One page per package, each loading that package's IIFE bundle straight from packages/*/dist/ and asserting what its README claims. Open a page and the checks run — the tab title reports PASS or FAIL.

These exist so a regression has somewhere to surface other than a game. Run npm run build first; the pages load the built bundles, not the source.

  • cards — deck, rendering, poker and the ace-high contract
  • puzzle — grid, tiles, the init() ordering
  • rpg — canvas, tile map, a running game loop
  • audio — Web Audio surface (needs a click for sound)
  • score-client — the offline queue, with no server
  • multiplayer — configuration, allowlist, board template
  • chat — the widget mounting with no server

chat and multiplayer are client halves: their pages deliberately do not connect. See each package's PROTOCOL.md for what a server must do.
